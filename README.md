## Overview
`EsepInvoiceEscrow.sol` is an educational smart contract prototype demonstrating fraud-proof B2B invoice factoring. It prevents invoice double-pledging via on-chain SHA-256 hash uniqueness and automates discounted liquidity payouts and maturity settlements using role-based access control.
